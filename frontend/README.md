# Vacation Management Frontend

Frontend application for the Vacation Management System built with Vue.js.

---

# Tech Stack

- Vue 3
- Vue Router
- Axios
- TypeScript
- TailwindCSS
- Vite

---

# Features

## Authentication
- Sign up
- Sign in
- Role selection:
  - Requester
  - Validator

---

## Requester Dashboard
- Submit vacation requests
- View personal vacation history
- View request status:
  - Pending
  - Approved
  - Rejected
- View validator comments

---

## Validator Dashboard
- View all vacation requests
- Filter requests by status
- Approve requests
- Reject requests
- Add comments when rejecting
