# Vacation Management Backend

Backend API for the Vacation Management System built with Node.js, Express, PostgreSQL and TypeORM.

---

# Tech Stack

- Node.js
- Express.js
- PostgreSQL
- TypeORM
- TypeScript
- dotenv

---

# Features

## Authentication
- User registration
- User login
- Role management:
  - Requester
  - Validator

---

## Vacation Requests
- Create vacation requests
- Retrieve vacation requests by user
- Retrieve all vacation requests
- Approve requests
- Reject requests
- Add comments to requests
